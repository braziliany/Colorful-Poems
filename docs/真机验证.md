## 二、本轮发现的问题

### 1. 彩云天气旧 Key 配额耗尽

- 实测返回：`status: failed`。
- 错误：`API quota is exhausted`。
- 影响：天气区域显示 fallback，不会崩溃。
- 处理：已由用户提供并确认写入新 Token；真机截图显示天气恢复。

### 2. 今日诗词缺少持久化 Token

- 原请求直接调用 `/sentence`，实测返回 `errCode: 2004`。
- 官方要求 iOS/桌面客户端先调用 `/token`，持久化后通过 `X-User-Token` 请求。
- 已小范围修复：首次获取并保存 Token，失效时刷新一次。
- 临时 Token 流程实测返回诗句、朝代和作者，且 Token 保持一致。
