## 验证步骤

1. 正常联网运行一次组件，确认天气、农历和诗词正常，并建立缓存。
2. 记录右下角“更新于 HH:mm”的时间。
3. 打开飞行模式，确保 Wi-Fi 与蜂窝网络均不可用。
4. 再次运行或预览中号组件。
5. 确认天气仍显示最后成功温度、湿度、AQI、预警和日出日落，而不是全部 --。
6. 确认右下角显示“缓存 · HH:mm”，时间与联网成功时间一致，不是本次渲染时间。
7. 确认农历仍显示最后成功内容，不出现“农历加载失败”。
8. 在无日程场景确认诗词使用最后成功缓存；有日程时确认日历事件仍从本机 Calendar 正常读取。
9. 确认右下角电池图标和百分比已经完全消失。
10. 确认 Midnight Theme、中号双栏、天气颜色、日期、预警和日程布局无变化。
11. 恢复网络并再次运行。
12. 确认右下角恢复“更新于 HH:mm”，天气使用新数据并刷新缓存。
13. 可选：临时破坏一个缓存 JSON 后运行，确认组件忽略损坏文件且不崩溃。
14. 可选：仅让农历或诗词接口失败，确认天气仍使用实时数据，各来源独立回退。

## 通过标准（已满足）

- 联网时写入最后成功缓存。
- 完全断网时使用缓存并明确标记。
- 无缓存或缓存损坏时安全进入 fallback。
- 单个 API 失败不影响其他数据源。
- 无电池 UI 或电池死代码。
- 无 Scriptable 日志错误。
