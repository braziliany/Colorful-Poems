# v1.1.2 真机验证清单

> 状态：自动化测试完成，等待 iPhone Scriptable 真机验证。
> 本阶段不创建 Tag 或 GitHub Release。

## RC 安装入口

1. 在 iPhone Safari 打开开发分支的 [`Installer-RC.js`](https://raw.githubusercontent.com/braziliany/Colorful-Poems/codex/v1.1.2-offline-cache/Installer-RC.js)。
2. 全选并复制源码，在 Scriptable 中新建脚本，例如命名为 `v1.1.2 RC 测试安装器`。
3. 运行该脚本，确认安装提示显示 `Scriptable Weather Widget v1.1.2 RC` 和分支 `codex/v1.1.2-offline-cache`。
4. 首次安装时在安全输入框填写彩云天气 Token。
5. 安装完成后打开独立脚本 `彩云诗词桌面天气 RC`；现有 Stable 脚本不会被读取或覆盖。

RC 安装器、专用清单和组件源码的远端地址均固定到开发分支，不使用 `main`。

## 准备

- 使用维护分支 codex/v1.1.2-offline-cache 的 src/widget.js。
- 保留本机有效彩云天气 Token。
- 确认 Scriptable 允许定位、日历与提醒事项权限。

## 验证步骤

1. 正常联网运行一次组件，确认天气、农历和诗词正常，并建立缓存。
2. 记录右下角“更新于 HH:mm”的时间。
3. 打开飞行模式，确保 Wi-Fi 与蜂窝网络均不可用。
4. 再次运行或预览中号组件。
5. 确认天气仍显示最后成功温度、湿度、AQI、预警和日出日落，而不是全部 --。
6. 确认右下角显示“缓存 · HH:mm”，时间与联网成功时间一致，不是本次渲染时间。
7. 确认农历仍显示最后成功内容，不出现“农历加载失败”。
8. 在无日程场景确认诗词使用最后成功缓存；有日程时确认日历事件仍从本机 Calendar 正常读取。
9. 确认右下角电池图标和百分比已经完全消失。
10. 确认 Midnight Theme、中号双栏、天气颜色、日期、预警和日程布局无变化。
11. 恢复网络并再次运行。
12. 确认右下角恢复“更新于 HH:mm”，天气使用新数据并刷新缓存。
13. 可选：临时破坏一个缓存 JSON 后运行，确认组件忽略损坏文件且不崩溃。
14. 可选：仅让农历或诗词接口失败，确认天气仍使用实时数据，各来源独立回退。

## 通过标准

- 联网时写入最后成功缓存。
- 完全断网时使用缓存并明确标记。
- 无缓存或缓存损坏时安全进入 fallback。
- 单个 API 失败不影响其他数据源。
- 无电池 UI 或电池死代码。
- 无 Scriptable 日志错误。
